# Suspicious URL Checker

## 📌 Project Description

Suspicious URL Checker is a basic cybersecurity application developed using Python.

The application allows a user to enter a website URL and checks some basic characteristics of the URL that may indicate suspicious or phishing activity.

## 🎯 Objective

The main objective of this project is to demonstrate how simple rule-based techniques can be used to analyze URLs and identify potentially suspicious characteristics.

## ⚙️ Features

- Accepts a URL from the user
- Checks whether a URL is received
- Checks the URL length
- Checks whether HTTPS is used
- Checks for suspicious keywords
- Displays the analysis result through a simple GUI

## 🛠️ Technology Used

- Python
- Tkinter
- VS Code
- GitHub

## 🔍 URL Checks

The application currently performs basic checks such as:

1. URL received or not
2. URL length
3. HTTPS usage
4. Suspicious keywords

## ▶️ How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project in VS Code.
4. Run `app.py`.
5. Enter a URL in the application.
6. Click the **Check URL** button.

## ⚠️ Limitations

This project uses basic rule-based detection. It cannot guarantee that a URL is completely safe or malicious.

A legitimate website may sometimes appear suspicious, and a sophisticated phishing website may not trigger the basic checks.
